# 🎬 Netflix Atlas

A production-grade **streaming content intelligence** system built on the Netflix Titles dataset.  
It combines a **Flask REST API**, **TF-IDF content-based recommendations**, and **K-Means clustering** with a polished browser frontend.

---

## 📂 Project Structure

```
netflix_atlas/
├── src/
│   └── api.py                  # Flask REST API (catalog, search, recommendations)
├── notebooks/
│   └── netflix_clustering.ipynb  # ML clustering pipeline
├── data/
│   └── netflix_titles.csv      # Netflix catalog dataset (8 800+ titles)

└── README.md
```

## 🤖 AI / ML Components

| Component | Technology | Purpose |
|-----------|-----------|---------|
| Content-based recommendations | TF-IDF + cosine similarity | Finds similar titles by genre, cast, description, country |
| Content clustering | K-Means | Groups titles by genre, rating, duration, and release year |
| Dimensionality reduction | PCA | 2-D visualisation of cluster structure |
| Feature engineering | MultiLabelBinarizer + StandardScaler | Converts multi-label genres & numerics into a suitable feature matrix |

## ⚙️ Setup & Run

### 1. Clone / download the project

```bash
git clone <your-repo-url>
cd netflix_atlas
```

### 2. Create a virtual environment

```bash
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Confirm the dataset is in place

```
data/netflix_titles.csv   ← must exist (8 800+ rows)
```

### 5. Start the Flask API

```bash
python src/api.py
# Server starts at http://127.0.0.1:5000
```

### 6. Open the frontend

Open `frontend/index.html` in any modern browser.  
> **Tip:** Use VS Code Live Server or `python -m http.server 8080` inside the `frontend/` folder to avoid CORS issues with some browsers.

```bash
cd frontend
python -m http.server 8080
# Then visit http://localhost:8080
```

## 🌐 API Reference

All endpoints return JSON. Base URL: `http://127.0.0.1:5000`

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/health` | Service health check |
| GET | `/api/summary` | Catalog statistics (total, movies, shows, top country/genre) |
| GET | `/api/catalog` | Paginated & filtered title list |
| GET | `/api/title/<show_id>` | Full metadata for one title |
| GET | `/api/recommendations?title=<name>` | Top-N similar titles |

**Catalog query parameters:**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `search` | string | `""` | Full-text search (title, genre, cast, description, country) |
| `type` | string | `""` | `Movie` or `TV Show` |
| `country` | string | `""` | Partial country match |
| `genre` | string | `""` | Partial genre match |
| `page` | int | `1` | Page number |
| `page_size` | int | `12` | Results per page (max 100) |

**Example requests:**

```bash
# Health
curl http://127.0.0.1:5000/api/health

# Search crime TV shows from South Korea
curl "http://127.0.0.1:5000/api/catalog?genre=crime&type=TV+Show&country=Korea"

# Recommendations for Squid Game
curl "http://127.0.0.1:5000/api/recommendations?title=Squid+Game&limit=8"
```

## 🚀 Scalability & Deployment

### Short-term improvements
- **Caching:** add `flask-caching` (Redis/Memcached) for the TF-IDF similarity matrix and frequent query results
- **Async workers:** swap Flask dev server for **Gunicorn + Gevent** (`gunicorn -w 4 -k gevent src.api:app`)
- **Pagination cursor:** replace offset pagination with keyset pagination for large result sets

### Deployment options

| Option | Steps |
|--------|-------|
| **Railway / Render** | `git push` — auto-detects Python, set `PORT` env var |
| **Docker** | `docker build -t netflix-atlas . && docker run -p 5000:5000 netflix-atlas` |
| **AWS Lambda** | Use `mangum` adapter for serverless Flask |
| **Vercel (frontend only)** | Deploy `frontend/` as a static site; point API to a hosted backend |

### Real-world use cases
- **Content discovery engine** for a streaming platform
- **Metadata enrichment pipeline** — pipe cluster labels into a downstream recommender
- **Analytics dashboard** for content acquisition teams
- **Cold-start recommendation fallback** when collaborative filtering lacks user history
